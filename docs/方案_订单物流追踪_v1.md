# 订单物流展示原型（2026-10-21）

## 现有数据

模拟 CSV 共 100 笔，57 笔同时有物流公司和运单号，43 笔没有；不存在只填一项的记录。物流数据已作为原始导入字段存入订单详情。仅凭公司、运单号和订单状态，无法得知真实揽收、站点扫描及签收时间。

## 页面原型

- 订单列表：有公司及运单号的显示“有物流”，无运单号显示“暂无运单”。
- 订单详情：新增“物流”卡片，展示物流公司、运单号、源订单当前状态、下单时间和数据导入时间。
- 阶段文案从当前订单状态归纳，例如“已发货”“运输中”“已签收”；标记“根据导入订单状态展示，非实时轨迹”。不绘制虚构节点或预计送达时间。
- 无物流信息时展示“尚无运单信息”；待付款、取消、退款状态不会误显示运输进度。

## 数据与边界

本期从已有 `import_payload` 和 `merchant_order` 字段只读计算，不新增表、不调用物流平台、不产生费用。后续若接真实物流 API，应单独评估授权、费用、运单归属和刷新策略。
