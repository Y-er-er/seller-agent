# 中文商铺订单 CSV 适配方案（2026-10-21）

## 问题与原型

现有“导入 CSV”入口保持原位置。识别中文 20 列订单表头后，将元精确换算为分、映射状态、生成订单行编号；导入前显示识别笔数和字段保存说明。英文模板仍支持。

## 金额语义

用户确认该 CSV 的“实付金额(元)”在待付款、取消等状态下表示应付或订单金额。因此新增 `order_amount_cent` 保存原列金额；`paid_cent` 仅保存可解释为当前已收的金额。待付款、取消、已退款为 0；其他状态按原列金额处理。订单详情分别展示订单金额和已收金额。

## 数据保存

新增 `merchant_order_import_payload`，按订单主键保存导入原始行 JSON（包括买家、地址、物流、备注），详情页仅卖家可见；不送给 AI 工具。原始行用于审计和未来字段化，不能作为平台实时状态。数据库迁移单独执行，不由应用自动建表。

## 校验

导入前检查表头、行数、订单号、数量、金额两位小数、商品金额和订单金额公式、同单状态与时间一致；错误指出 CSV 行号。转换只在本地浏览器进行，预览不写库。导入仍按逐单 API 写入并保持订单号幂等冲突规则。
